# Учебный планер — инструкция по установке

Займёт около 15 минут. Всё бесплатно, банковская карта не нужна.

Понадобятся два сервиса:
- **Supabase** — база данных и хранилище файлов (задачи, пары, хвосты, .docx).
- **GitHub Pages** — хостинг самого приложения, твой адрес вида `логин.github.io/planner`.

---

## Шаг 1. Создай проект в Supabase

1. Открой https://supabase.com и нажми **Start your project**. Удобнее всего войти через GitHub (шаг 5), так что можешь сначала зарегистрироваться на GitHub.
2. Нажми **New project**.
3. Заполни:
   - **Name:** `planner`
   - **Database Password:** придумай и сохрани куда-нибудь (в приложении он не понадобится).
   - **Region:** `Central EU (Frankfurt)`.
4. Нажми **Create new project** и подожди 1–2 минуты, пока проект создаётся.

## Шаг 2. Создай таблицы

1. В левом меню открой **SQL Editor**.
2. Нажми **New query** (или «+»).
3. Открой файл `supabase.sql` из архива любым текстовым редактором (Блокнот подойдёт), скопируй **весь** текст и вставь в окно запроса.
4. Нажми **Run** (или Ctrl+Enter).
5. Внизу должно появиться **Success. No rows returned**.

## Шаг 3. Отключи подтверждение почты

Без этого Supabase будет требовать подтверждать адрес по ссылке из письма.

1. Левое меню → **Authentication** → **Sign In / Providers** (в некоторых версиях: **Providers** → **Email**).
2. Найди переключатель **Confirm email** и выключи его.
3. Нажми **Save**.

## Шаг 4. Скопируй адрес проекта и ключ

1. Левое меню → значок шестерёнки **Project Settings** → **API Keys** (или **Data API**).
2. Скопируй **Project URL**. Он выглядит так: `https://abcdefghijklmnop.supabase.co`.
3. Скопируй ключ одним из двух способов:
   - вкладка **Legacy API Keys** → ключ **anon public** (начинается с `eyJ...`), или
   - ключ **Publishable key** (начинается с `sb_publishable_...`).

> ⚠️ Не бери **service_role** или **secret** ключ. Его нельзя публиковать.

Оба значения понадобятся на шаге 6.

## Шаг 5. Загрузи приложение на GitHub

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Справа вверху «+» → **New repository**.
3. **Repository name:** `planner`. Оставь **Public**. Нажми **Create repository**.
4. На странице нового репозитория нажми ссылку **uploading an existing file**.
5. Распакуй архив и перетащи **все файлы** (не папку, а именно файлы внутри неё) в окно браузера:
   `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `supabase.sql`, `README.md`.
6. Внизу нажми **Commit changes**.

## Шаг 6. Впиши ключи в config.js

1. В репозитории нажми на файл `config.js`, затем на значок карандаша ✏️ (Edit).
2. Замени `ВСТАВЬ_СЮДА_PROJECT_URL` на Project URL из шага 4.
3. Замени `ВСТАВЬ_СЮДА_КЛЮЧ` на ключ из шага 4.
   Кавычки оставь. Получится примерно так:
   ```js
   supabaseUrl: "https://abcdefghijklmnop.supabase.co",
   supabaseKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
   ```
4. Нажми **Commit changes…** → **Commit changes**.

## Шаг 7. Включи GitHub Pages

1. В репозитории: **Settings** → слева **Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Подожди 1–2 минуты и обнови страницу. Вверху появится адрес вида
   `https://твой-логин.github.io/planner/`. Это и есть твоё приложение.

## Шаг 8. Создай аккаунт в приложении (на ПК)

1. Открой адрес из шага 7 в Chrome или Edge.
2. Выбери **Регистрация**, впиши свою почту и пароль (минимум 6 символов) → **Создать аккаунт**.
3. Готово, ты внутри.

**Установить как программу на ПК:** в адресной строке справа нажми значок «Установить» (монитор со стрелкой) или меню ⋮ → **Установить приложение**. Появится ярлык на рабочем столе, приложение откроется в отдельном окне.

## Шаг 9. Установи на iPhone

1. Открой тот же адрес в **Safari** (именно Safari).
2. Кнопка «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Открой приложение **с иконки** и войди с той же почтой и паролем (вкладка **Вход**).
   Важно: войти нужно именно в приложении с иконки, а не в Safari. Это разные «хранилища».

Дальше вход запоминается, и вводить пароль больше не нужно.

## Шаг 10 (по желанию). Запрети регистрацию посторонним

Твои данные и так видишь только ты. Но чтобы никто другой не мог создать аккаунт в твоей базе:
Supabase → **Authentication** → **Sign In / Providers** → выключи **Allow new users to sign up** → **Save**.

## Как пользоваться

- **Закинуть задание с ПК:** перетащи .docx в окно приложения. Подпиши, что это за файл, добавь пояснения, выбери тип задания и срок → **Добавить**. На iPhone задача появится через пару секунд вместе с полным текстом задания. Оригинал можно скачать кнопкой.
- **Изменить или удалить:** на iPhone смахни строку влево. На ПК наведи мышь, появятся кнопки ✏️ и 🗑. После удаления несколько секунд доступна кнопка **Отменить**.
- **Без интернета:** приложение открывается и работает. Изменения сохранятся на устройстве и отправятся в базу, когда появится сеть. Прикреплять и открывать файлы можно только с интернетом.
- **Резервная копия:** вкладка «Сегодня» → внизу «Сохранить резервную копию».

## Если что-то не работает

| Что видишь | Что делать |
|---|---|
| «Почти готово. Не вписаны ключи базы» | Проверь шаг 6. После сохранения подожди минуту и обнови страницу. |
| «Неверная почта или пароль» | Проверь раскладку. Если аккаунта ещё нет, выбери «Регистрация». |
| «Почта не подтверждена» | Выключи **Confirm email** (шаг 3) или нажми ссылку в письме от Supabase. |
| «Не удалось загрузить данные: relation "items" does not exist» | Не выполнен SQL из шага 2. |
| Не загружаются файлы | Проверь, что SQL из шага 2 выполнился целиком, без ошибок. |
| Страница GitHub выдаёт 404 | Подожди пару минут после шага 7. Проверь, что файлы лежат в корне репозитория, а не в папке. |
| Supabase написал, что проект на паузе | Бесплатные проекты засыпают после 7 дней без использования. Открой supabase.com → проект → **Restore project**. Данные не теряются. |

## Как обновлять приложение

Если я пришлю новую версию `index.html`: в репозитории нажми **Add file** → **Upload files**, перетащи новый файл → **Commit changes**. `config.js` не трогай, иначе ключи придётся вписывать заново. Через пару минут после загрузки закрой и снова открой приложение (иногда два раза), и подтянется новая версия.
